# Iris Flower Classification

## Project Description

This project uses Machine Learning to classify Iris flowers into three different species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

The classification is performed using the flower's sepal and petal measurements.

## Dataset

The Iris dataset contains measurements of Iris flowers.

The features used are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable is the flower species.

## Machine Learning Algorithm

Random Forest Classifier is used to train the machine learning model.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps

1. Load the Iris dataset
2. Explore the dataset
3. Check missing values
4. Analyze the data using graphs
5. Prepare the data for machine learning
6. Split the data into training and testing sets
7. Train the Random Forest model
8. Evaluate the model
9. Display the confusion matrix
10. Predict the species of a new Iris flower

## Example Prediction

The model can predict the species of a new flower based on measurements such as:

- Sepal Length = 5.1
- Sepal Width = 3.5
- Petal Length = 1.4
- Petal Width = 0.2

The model predicts the corresponding Iris species.

## Conclusion

The project demonstrates how Machine Learning can be used to classify Iris flowers based on their sepal and petal measurements.
